# حضوربان | Hozourban

سامانه محلی حضور و غیاب مدارس با Flask و SQLite.

## نصب سریع

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python run.py
```

سپس مرورگر: **http://127.0.0.1:5000/**

- بار اول: ویزارد ساخت حساب مدیر
- نقش‌ها و مجوزهای پیش‌فرض به‌صورت خودکار ساخته می‌شوند

## قابلیت‌های فعلی

| قابلیت | وضعیت |
|--------|--------|
| ساختار Flask + SQLite | آماده |
| راه‌اندازی مرورگر‌محور | آماده |
| ورود / خروج + CSRF | آماده |
| نقش‌ها و مجوزها (سیستم / مدیر مدرسه / معلم / مشاهده‌گر) | آماده |
| مدیریت مدارس و سال تحصیلی | آماده |
| مدیریت کلاس‌ها | آماده |
| مدیریت دانش‌آموزان و ثبت‌نام در کلاس | آماده |
| ثبت حضور و غیاب (حاضر / غایب / تأخیر / موجه) | آماده |
| داشبورد خلاصه | آماده |
| API محصولی کامل | در مراحل بعد |
| استقرار امن LAN | نیازمند WSGI و hardening |

## جریان کاری پیشنهادی

1. ورود با حساب مدیر
2. ثبت **مدرسه** (+ سال تحصیلی)
3. ساخت **کلاس**
4. ثبت **دانش‌آموز** و اتصال به کلاس
5. از منوی **حضور و غیاب** جلسه امروز را ثبت کنید

## مجوزهای پیش‌فرض

- `system_admin` — همه دسترسی‌ها
- `school_admin` — مدیریت مدرسه، کلاس، دانش‌آموز، حضور
- `teacher` — مشاهده کلاس/دانش‌آموز + ثبت حضور
- `viewer` — فقط مشاهده و گزارش

## نکات

- قبل از استفاده واقعی `SECRET_KEY` را در `.env` عوض کنید.
- برای تغییر ساختار بعدی از Flask-Migrate استفاده کنید.
- سرور `python run.py` فقط برای توسعه است.
